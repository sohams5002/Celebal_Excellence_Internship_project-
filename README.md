# Celebal Excellence Internship - Final Project: Lead Scoring

Final project for the Celebal Excellence Internship Program at Celebal Technologies (Jun-Aug 2026).

A machine learning pipeline that scores sales leads so teams can prioritise the prospects most likely to convert. The notebook walks through the full workflow: cleaning and preprocessing the lead dataset, feature preparation, training and comparing classification models, and evaluating results.

## Files

- `Lead scoring.ipynb` - the full analysis and modelling notebook
- `Lead Scoring.csv.zip` - the dataset

## Run it

```
pip install pandas numpy scikit-learn jupyter
jupyter notebook "Lead scoring.ipynb"
```

## Stack

Python, Pandas, scikit-learn, Jupyter
